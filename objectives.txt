You are an expert Python AI engineer and educational-project developer.

This is an academic project based specifically on **Unit 3: Logical Agents / Propositional Logic**. The implementation must demonstrate the concepts I have studied in class rather than merely creating a visual pathfinding simulation.

## 1. PROJECT SCENARIO

Create an autonomous Mars rover operating on a 2D grid representing a section of the Martian surface.

The grid contains:

* Safe terrain
* Unknown terrain
* Hazard zones
* Radiation zones
* The rover's starting position
* A target/goal position

The rover must autonomously navigate from its start position to the goal while continuously:

1. Perceiving environmental information.
2. Updating its Knowledge Base (KB).
3. Using Propositional Logic to infer what is safe or unsafe.
4. Deciding whether movement is allowed.
5. Moving only when logically justified.
6. Updating the KB after every action/perception.
7. Printing a detailed live console log showing the reasoning process.

The project must clearly demonstrate that the rover is a **Knowledge-Based Agent**, not simply an A* pathfinder.

# 12. CNF CONVERSION

Implement a CNF conversion pipeline for the logical expressions used by the inference engine.

The conversion should demonstrate the transformations I studied:

### Implication elimination

α → β

becomes:

¬α ∨ β

### Biconditional elimination

α ↔ β

becomes:

(α → β) ∧ (β → α)

### De Morgan's Laws

¬(α ∧ β)

becomes:

¬α ∨ ¬β

and

¬(α ∨ β)

becomes:

¬α ∧ ¬β

### Double negation

¬(¬α)

becomes:

α

Use these transformations internally wherever required by the resolution engine.

# 22. AUTONOMOUS DECISION-MAKING

The rover should not simply follow a predetermined path.

At every step:

1. Look at neighboring cells.
2. Generate possible actions.
3. Query the KB for each candidate.
4. Reject logically unsafe actions.
5. Prefer a safe action that moves closer to the goal.
6. Update the KB.
7. Move.
8. Repeat.

¬CanMove_Right

CanMove_Up

Decision:
MOVE UP
